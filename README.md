# 💈 HairDay

Aplicação web para agendamento de corte de cabelo, desenvolvida para treinar o uso de JavaScript, bibliotecas e consumo de API.

## 📖 Sobre

Projeto que simula um sistema de agendamentos, com back-end simulado via json-server e build gerenciado pelo Webpack.

## 🚀 Tecnologias

- JavaScript
- [Webpack](https://webpack.js.org/)
- [Day.js](https://day.js.org/)
- [json-server](https://github.com/typicode/json-server)
- Babel
